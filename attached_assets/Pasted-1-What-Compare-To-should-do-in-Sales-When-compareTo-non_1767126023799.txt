2) The #1 reason your dashed lines aren’t showing
Usually one of these:


comparisonData is a different length / different x labels than data


You’re rendering compare lines but the keys don’t exist in the same objects as current


hasComparisonData check fails because values are 0/undefined


So: merge them into one array keyed by a shared “label”.

3) Drop-in helper: merge current + compare by label
Use this in your Sales component.
function mergeSalesSeries(
  current: Array<{ label: string; total: number; food: number; bar: number; gaming: number }>,
  compare?: Array<{ label: string; total: number; food: number; bar: number; gaming: number }>
) {
  const map = new Map<string, any>();

  for (const p of current) {
    map.set(p.label, {
      label: p.label,
      current_total: p.total ?? 0,
      current_food: p.food ?? 0,
      current_bar: p.bar ?? 0,
      current_gaming: p.gaming ?? 0,
    });
  }

  if (compare) {
    for (const p of compare) {
      const existing = map.get(p.label) ?? { label: p.label };
      map.set(p.label, {
        ...existing,
        compare_total: p.total ?? 0,
        compare_food: p.food ?? 0,
        compare_bar: p.bar ?? 0,
        compare_gaming: p.gaming ?? 0,
      });
    }
  }

  // keep the same order as current series
  return current.map((p) => map.get(p.label));
}

Then:
const mergedData = useMemo(
  () => mergeSalesSeries(currentSeries, comparisonSeries),
  [currentSeries, comparisonSeries]
);

const hasCompare = useMemo(
  () => mergedData.some((p: any) => p.compare_total != null),
  [mergedData]
);


4) Recharts: render solid + dashed in the SAME chart
Example for line view (works the same for Food/Bar/Gaming toggles):
{visible.total && (
  <>
    <Line dataKey="current_total" dot={false} />
    {hasCompare && (
      <Line
        dataKey="compare_total"
        dot={false}
        strokeDasharray="6 6"
        opacity={0.7}
      />
    )}
  </>
)}

Do the same pattern for current_food / compare_food, etc.
For Bar view
Bars can’t be dashed cleanly; the typical UI is:


current = normal bars


compare = outlined bars or lighter bars behind


Simplest:
{visible.total && <Bar dataKey="current_total" />}
{hasCompare && visible.total && <Bar dataKey="compare_total" opacity={0.35} />}


5) Where does comparisonSeries come from?
Whatever your Insights “Compare To” dropdown is doing, your Sales section needs access to the same selection + date range.
You want this flow:
Filters & Controls (parent)
→ computes dateRange, viewBy, compareTo
→ fetches metrics AND comparisonMetrics
→ passes both down to <SalesSection metrics={metrics} comparison={comparisonMetrics} />
If SalesSection is currently fetching by itself, it won’t know about compareTo unless you wire it in.
