2️⃣ Make each manager row compact & aligned

Replace your ManagerRow with this version:

function ManagerRow({ label, value, onChange }) {
  return (
    <div className="flex items-center gap-3 rounded-lg border border-white/10 bg-black/10 px-4 py-3">
      <div className="w-20 text-xs font-semibold uppercase tracking-wide text-white/70">
        {label}
      </div>
      <input
        value={value || ""}
        onChange={(e) => onChange?.(e.target.value)}
        placeholder="Name"
        className="h-9 w-full rounded-md border border-white/10 bg-black/20 px-3 text-sm text-white outline-none focus:border-white/25"
      />
    </div>
  );
}

Why this works

w-20 keeps labels aligned

Inputs stretch evenly

Cards stay same height

Eye scans left → right naturally
