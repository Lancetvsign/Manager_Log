Got it — keep the running list intact, but only show completed items (greyed out) if they were completed on the currently selected log date. Tomorrow, those completed rows simply won’t render (but they still exist in the DB as completed).

Here’s the clean way to do it.

✅ Data change (one column)

Add a completedAt timestamp (or date) on maintenance items.

When you mark an item completed: set status = "completed" and completedAt = now()

When you undo: set status = "open" and completedAt = null

Drizzle schema
export const maintenanceItems = pgTable("maintenance_items", {
  // ...
  status: text("status").notNull().default("open"), // open | completed
  completedAt: timestamp("completed_at"), // nullable
});


Migration SQL:

ALTER TABLE maintenance_items
ADD COLUMN IF NOT EXISTS completed_at TIMESTAMPTZ;

✅ Rule for what to SHOW on a given day

Let selectedDate = the log’s date (NOT “today” on the computer).

Show:

All OPEN items (old + new) ✅

Only COMPLETED items whose completedAt falls on selectedDate ✅ (greyed out)

Completed items from previous days ❌ (hidden)

✅ Backend query (Drizzle)

Assuming you have clubId and selectedDate (YYYY-MM-DD) available:

import { and, or, eq, sql, asc } from "drizzle-orm";

const dayStart = `${selectedDate} 00:00:00`;
const nextDayStart = `${selectedDate} 00:00:00`; // we’ll add + 1 day in SQL

const items = await db
  .select()
  .from(maintenanceItems)
  .where(
    and(
      eq(maintenanceItems.clubId, clubId),
      or(
        // 1) open items always show
        eq(maintenanceItems.status, "open"),

        // 2) completed items only if completedAt is on selectedDate
        and(
          eq(maintenanceItems.status, "completed"),
          sql`${maintenanceItems.completedAt} >= ${selectedDate}::date
              AND ${maintenanceItems.completedAt} < (${selectedDate}::date + interval '1 day')`
        )
      )
    )
  )
  .orderBy(
    // open items first, then completed-today
    sql`CASE WHEN ${maintenanceItems.status} = 'open' THEN 0 ELSE 1 END`,
    asc(maintenanceItems.createdAt)
  );


Return these items to the UI in your existing “running maintenance list” endpoint.

  .set({ status: "open", completedAt: null })
