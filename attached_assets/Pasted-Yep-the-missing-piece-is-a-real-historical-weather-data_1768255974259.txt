Best “accurate last year weather” option (easy to ship)
✅ Open-Meteo Historical / Archive API (ERA5 reanalysis)

Works by lat/lon + date (no station selection).

No API key needed.

Gives you hourly/daily historical values (temp, wind, weathercode, etc.).

This is the cleanest for your app because you already have (or can request) user location, and you don’t want to manage weather stations.

The weekday-to-weekday rule you want

If you want Friday compared to Friday, don’t do “minus 365 days”.

Do minus 364 days (52 weeks):

364 days = 52 weeks → same weekday every time.

(Leap years get tricky if you must compare “same calendar date”, but your requirement is weekday alignment.)

So for “Last Year” in your UI, call it:
“52 weeks ago (same weekday)” (or just “Last Year (weekday matched)”).
