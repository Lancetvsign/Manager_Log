This is a great addition because it turns the calculator from just cost justification into revenue generation. Digital signage (The TV Sign) is actually one of the easiest things to quantify in a club environment.

The key is to treat signage as two revenue drivers:

1️⃣ Increased in-club spending (traffic / impulse purchases)
2️⃣ Ad revenue from local businesses

And it needs to be toggleable ON/OFF in the calculator.

How to Integrate Digital Signage Into the Calculator
1️⃣ New Toggle Input

Add a toggle in the Operations section:

When enabled, reveal inputs:

Ad slots per TV

Example defaults:

Ad price: $50/month

These should also be editable assumptions in Admin just like the other percentages.

2️⃣ Revenue Model
A) Ad Revenue Formula
monthlyAdRevenue =
  TVs
  × adSlotsPerTV
  × adPricePerMonth

Annual:

annualAdRevenue = monthlyAdRevenue × 12

Example:

2 TVs
8 ads
$50/month

= 2 × 8 × 50
= $800/month
= $9,600/year
B) Traffic / Spending Lift

Digital signage increases impulse purchases.

Industry average lift:

2–5% bar revenue increase

Formula:

signageTrafficRevenue =
  annualBarRevenue × trafficLiftPct

Example:

$3000 weekly bar
= $156,000 annually

3% lift

= $4,680/year
3️⃣ Total Signage Impact
totalSignageRevenue =
  annualAdRevenue + signageTrafficRevenue

Example:

$9,600 ads
+ $4,680 traffic

= $14,280/year

6️⃣ Make It Toggleable in the Engine

In calc.ts add something like:

const signageEnabled = Boolean(inputs.signageEnabled);

let signageRevenue = 0;

if (signageEnabled) {

  const tvs = num(inputs.signageTVs);
  const adSlots = num(inputs.adSlotsPerTV);
  const adPrice = num(inputs.adPricePerMonth);
  const trafficLift = num(settings.signage_traffic_lift_pct);

  const monthlyAds = tvs * adSlots * adPrice;
  const annualAds = monthlyAds * 12;

  const annualBar = weeklyBar * 52;
  const trafficRevenue = annualBar * trafficLift;

  signageRevenue = annualAds + trafficRevenue;
}

totalOpportunity += signageRevenue;

Return:

signageRevenue
