3) Make WeatherWide smaller when compact is true

Update WeatherWide.jsx to support a compact mode (so the weather box shrinks and doesn’t dominate).

Replace your component with this version:

import React from "react";

export default function WeatherWide({
  title = "Today",
  temp = "—",
  condition = "—",
  wind = "—",
  icon = "☁️",
  muted = false,
  compact = false,
}) {
  return (
    <div
      className={[
        "w-full rounded-xl border border-white/10 bg-black/10",
        compact ? "px-4 py-3" : "px-5 py-4",
        muted ? "opacity-80" : "",
      ].join(" ")}
    >
      <div className="flex items-center justify-between">
        <div className="flex items-center gap-3">
          <div className={compact ? "text-xl" : "text-2xl"}>{icon}</div>

          <div className="leading-tight">
            <div className="text-[10px] font-semibold uppercase tracking-wide text-white/50">
              {title}
            </div>

            <div className="flex items-baseline gap-2">
              <div className={compact ? "text-3xl font-semibold text-white" : "text-4xl font-semibold text-white"}>
                {temp}°
              </div>
              <div className="text-xs text-white/60">{condition}</div>
            </div>
          </div>
        </div>

        <div className="text-right">
          <div className="text-[10px] font-semibold uppercase tracking-wide text-white/50">
            Wind
          </div>
          <div className="text-xs font-medium text-white/80">{wind} mph</div>
        </div>
      </div>
    </div>
  );
}

What this fixes (based on your screenshot)

The top-left area becomes visually “anchored” and larger (title/date now deserve the space)

The weather no longer looks like it’s consuming the whole header

The stats become true “top-right quick metadata,” separate from weather

The layout uses the full width and feels intentional

If you want the weather to fill exactly the remaining space without ever feeling too big, change the grid columns to:
