In your shared schema where managerLogs is defined (something like @shared/schema.ts):

// Before

➕ Add:
export const managerLogs = pgTable("manager_logs", {
  id: serial("id").primaryKey(),
  clubId: integer("club_id").notNull(),
  date: date("date").notNull(),
  dayOfWeek: varchar("day_of_week", { length: 16 }).notNull(),

  // existing field
  managerName: varchar("manager_name", { length: 120 }),

  // NEW fields
  amManagerName: varchar("am_manager_name", { length: 120 }),
  pmManagerName: varchar("pm_manager_name", { length: 120 }),
  kitchenManagerName: varchar("kitchen_manager_name", { length: 120 }),

  // ...rest
});


Run your Drizzle migration to add:

ALTER TABLE manager_logs
  ADD COLUMN am_manager_name varchar(120),
  ADD COLUMN pm_manager_name varchar(120),
  ADD COLUMN kitchen_manager_name varchar(120);

2️⃣ API / routes: include new fields in load & save

Where you insert/update logs in server/routes.ts (or similar):

Insert / update payload (TS type):
export interface ManagerLogInput {
  // existing
  managerName?: string;

  // new
  amManagerName?: string | null;
  pmManagerName?: string | null;
  kitchenManagerName?: string | null;

  // ...rest
}

When saving:
await db
  .insert(managerLogs)
  .values({
    clubId,
    date,
    dayOfWeek,
    managerName: body.managerName || null,
    amManagerName: body.amManagerName || null,
    pmManagerName: body.pmManagerName || null,
    kitchenManagerName: body.kitchenManagerName || null,
    // ...
  });


And for updates:

await db
  .update(managerLogs)
  .set({
    managerName: body.managerName ?? null,
    amManagerName: body.amManagerName ?? null,
    pmManagerName: body.pmManagerName ?? null,
    kitchenManagerName: body.kitchenManagerName ?? null,
    // ...
  })
  .where(eq(managerLogs.id, logId));

When fetching a log:

Make sure these fields are in your select:

const log = await db.query.managerLogs.findFirst({

3️⃣ UI: add AM / PM / Kitchen manager fields

On your Daily Manager Log Entry header card (where you currently have Date / Day of Week / Manager Name), we’ll expand it.

State shape

In your React state for the log:

const [form, setForm] = useState({
  // existing
  managerName: log?.managerName || "",
  // new
  amManagerName: log?.amManagerName || "",
  pmManagerName: log?.pmManagerName || "",
  kitchenManagerName: log?.kitchenManagerName || "",
  // ...
});

Change handlers
function updateField<K extends keyof typeof form>(key: K, value: (typeof form)[K]) {
  setForm((prev) => ({ ...prev, [key]: value }));
}

Header layout (example JSX)

Right under Date / Day of Week, add a row:

<div className="row g-3 mt-2">
  <div className="col-md-4">
    <label className="form-label small mb-1">AM Manager</label>
    <input
      type="text"
      className="form-control form-control-sm"
      value={form.amManagerName}
      onChange={(e) => updateField("amManagerName", e.target.value)}
      placeholder="e.g. Sarah"
    />
  </div>

  <div className="col-md-4">
    <label className="form-label small mb-1">PM Manager</label>
    <input
      type="text"
      className="form-control form-control-sm"
      value={form.pmManagerName}
      onChange={(e) => updateField("pmManagerName", e.target.value)}
      placeholder="e.g. Mike"
    />
  </div>

  <div className="col-md-4">
    <label className="form-label small mb-1">Kitchen Manager</label>
    <input
      type="text"
      className="form-control form-control-sm"
      value={form.kitchenManagerName}
      onChange={(e) => updateField("kitchenManagerName", e.target.value)}
      placeholder="e.g. Chef Ana"
    />
  </div>
</div>


If you want to keep your original “Manager Name” field as Primary Manager on Duty, just relabel it:

<label className="form-label small mb-1">Primary Manager on Duty</label>
