1️⃣ Change button text: Add Photo → Change Photo
Add an id to your button (if not already)
<button
  type="button"
  id="photoBtn"
  onclick="document.getElementById('photoInput').click()"
  class="px-3 py-2 rounded-lg border border-slate-700 bg-slate-950/40 text-slate-200 text-sm hover:bg-slate-800/40"
>
  Add Photo
</button>

Update your existing JS (small change)
const input = document.getElementById("photoInput");
const wrap = document.getElementById("thumbWrap");
const img = document.getElementById("thumbImg");
const clearBtn = document.getElementById("clearPhoto");
const photoBtn = document.getElementById("photoBtn");

input.addEventListener("change", () => {
  const file = input.files?.[0];
  if (!file) return;

  img.src = URL.createObjectURL(file);
  wrap.classList.remove("hidden");
  wrap.classList.add("flex");

  // 👇 CHANGE BUTTON TEXT
  photoBtn.textContent = "Change Photo";
});

Reset button text when photo is removed
clearBtn.addEventListener("click", () => {
  input.value = "";
  img.src = "";
  wrap.classList.add("hidden");
  wrap.classList.remove("flex");

  // 👇 RESET BUTTON TEXT
  photoBtn.textContent = "Add Photo";
});

2️⃣ Click thumbnail to open larger preview (lightbox)

This is a very lightweight modal, no library needed.

Add this HTML once (near bottom of page)
<div
  id="photoModal"
  class="fixed inset-0 z-50 hidden items-center justify-center bg-black/70"
>
  <img
    id="photoModalImg"
    class="max-h-[90vh] max-w-[90vw] rounded-xl border border-slate-700"
  />
</div>

Make thumbnail clickable

Update the thumbnail <img>:

<img
  id="thumbImg"
  class="h-9 w-9 rounded-md object-cover border border-slate-700 cursor-pointer hover:ring-2 hover:ring-emerald-500"
  alt="Preview"
/>

Add modal JS (very small)
const modal = document.getElementById("photoModal");
const modalImg = document.getElementById("photoModalImg");

img.addEventListener("click", () => {
  if (!img.src) return;
  modalImg.src = img.src;
  modal.classList.remove("hidden");
  modal.classList.add("flex");
});

modal.addEventListener("click", () => {
  modal.classList.add("hidden");
  modal.classList.remove("flex");
});
