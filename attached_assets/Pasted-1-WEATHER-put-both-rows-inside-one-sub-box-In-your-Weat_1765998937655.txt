1) WEATHER: put both rows inside one sub-box

In your Weather panel, wrap both rows in ONE container:

<div className="mt-3 rounded-xl border border-white/10 bg-black/10 p-3">
  <div className="grid gap-2">
    <WeatherRow title="Today"  temp={todayTemp}  condition={todayCond}  wind={todayWind}  compact />
    <WeatherRow title="Last Year" temp={lyTemp} condition={lyCond} wind={lyWind} muted compact />
  </div>
</div>

Update WeatherRow to be compact

Replace your WeatherRow with:

function WeatherRow({ title, temp, condition, wind, muted, compact }) {
  return (
    <div className={`flex items-center justify-between ${muted ? "opacity-75" : ""}`}>
      <div className="flex items-center gap-2">
        <span className="text-base leading-none">☀️</span>

        <div className="leading-tight">
          <div className="text-[10px] font-semibold uppercase tracking-wide text-white/45">
            {title}
          </div>

          <div className="flex items-baseline gap-2">
            {/* smaller temp so both rows fit */}
            <div className="text-2xl font-semibold text-white leading-none">
              {temp}°
            </div>
            <div className="text-xs text-white/60">{condition}</div>
          </div>
        </div>
      </div>

      <div className="text-right leading-tight">
        <div className="text-[10px] font-semibold uppercase tracking-wide text-white/45">
          Wind
        </div>
        <div className="text-xs font-medium text-white/75">{wind} mph</div>
      </div>
    </div>
  );
}


What changed: temp is now text-2xl (was bigger), spacing is tighter, no extra padding per-row.

2) DRAWING: make one sub-box that contains BOTH Daily + Weekly

In the Drawing panel, do the same: one inner sub-box:

<div className="mt-3 rounded-xl border border-white/10 bg-black/10 p-3">
  <div className="grid gap-2">
    <StatMini label="Daily" value={dailyNumber ?? "—"} compact />
    <StatMini label="Weekly" value={weeklyNumber ?? "—"} compact />
  </div>
</div>

Update StatMini to compact
function StatMini({ label, value, compact }) {
  return (
    <div className="rounded-lg border border-white/10 bg-black/20 px-3 py-2">
      <div className="text-[10px] font-semibold uppercase tracking-wide text-white/45">
        {label}
      </div>
      <div className="mt-0.5 text-sm font-semibold text-white/90 leading-none">
        {value}
      </div>
    </div>
  );
}

3) If it STILL barely clips: drop panel height by controlling sub-box height

If your outer panel height is fixed, the safest “never overflow” trick is:

<div className="mt-3 h-[96px] rounded-xl border border-white/10 bg-black/10 p-3">
  <div className="grid h-full grid-rows-2 gap-2">
    ...
  </div>
</div>


Use that on both Weather + Drawing sub-box containers.
